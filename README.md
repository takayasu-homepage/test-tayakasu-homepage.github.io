# 情報系研究室HP デザイン案

Jekyll + Bootstrapを想定した静的サイトのデザイン案です。

## 構成

- `index.html`: トップページ
- `assets/css/style.css`: 追加スタイル
- `assets/js/news.js`: CSV読み込み処理
- `assets/data/news.csv`: NEWS表示用CSV
- `_config.yml`: Jekyll設定

## 確認方法

Jekyll環境がある場合:

```bash
jekyll serve
```

Jekyllがない場合も、静的サーバーで確認できます:

```bash
python -m http.server 4000
```

その後、ブラウザで `http://localhost:4000/` を開いてください。

## 著書ページの更新

`data/csv/book.csv` の1行が1冊（または1掲載物）に対応します。表紙は `data/images/book/` に保存し、`image` にその相対パスを指定します。共著・共同編集は同じ本を重複登録しません。

- `people`: `misako`、`hideki`、または `misako;hideki`。著者・編集者・訳者・分担執筆者としての参加を確認して指定します。空欄の本は「すべて」にのみ表示します。
- `year`: 並び順と年表示に使う初版の出版年。同年の本はCSVの記載順で表示します。
- `published`: 表示用の出版年月。新装版がある場合も初版の年月を記載します。
- `edition_year`: 掲載している表紙が新装版の場合、その刊行年。`note` にも「○年新装版刊行」と記載します。
- `isbn`: 購入リンク先の版のISBN。新装版の場合は新装版の番号を記載します。画面には自動表示しません。
- `source_url` / `image_source_url`: 書誌情報と表紙画像の確認元。画面には表示しません。
- `authors`: 編集者1名は `/ Ed.`、複数名は `/ Eds.`。分担執筆・解説・監訳なども実際の役割を明記します。

初版と新装版は1行にまとめ、表紙と購入リンクを新装版にそろえます。今回追加したSpringerの3冊は、出版社のハードカバー発売日を `year` / `published` に使用し、異なる書誌年を `note` に併記しています。

フィルターはページ再読み込みなしで一覧と上部の本棚を切り替えます。表示件数は雑誌を含むため「件」で表示しています。


## 研究業績ページの更新

`result.html` に論文・招待講演／学会発表・メディア掲載／その他・研究来訪者を表示します。
初期表示は「論文」「すべての年」「すべての種類」。各分類へ切り替えたときも絞り込みを解除します。
年は各分類のCSVから自動で作られ、新しい年から表示します。2028年の記録を追加して保存し、ページを再読み込みすると、一覧と年の選択肢に2028年が追加されます。
公開先で表示するには更新したCSVも公開先に反映する必要があります。

### 読み込むファイル

| 分類 | `data/csv/` 内のファイル |
| --- | --- |
| 英語・査読あり | `pub_EnPeer.csv` |
| 日本語・査読あり | `pub_JpPeer.csv` |
| 日本語・査読なし | `pub_JpNot.csv` |
| 招待講演・学会発表 | `conference.csv` |
| メディア掲載・その他 | `media.csv` |
| 研究来訪者 | `visitor.csv` |

CSVは、1行目に項目名を持つ標準的なカンマ区切り形式です。UTF-8（BOM付き）で保存しています。Excelでは**「CSV UTF-8（コンマ区切り）」**を選んで保存してください。「CSV（コンマ区切り）」だけだと環境によって文字コードが変わるため、UTF-8を指定します。

### 編集方法

1. 対象のCSVをExcelなどで開き、最後に行を追加するか、既存の行を編集します。
2. 先頭の項目名は変更せず、各セルに情報を入力します。列の順番は入れ替えられます。
3. UTF-8のCSVで保存して、ページを再読み込みします。年の選択肢は自動で更新されます。

著者名にカンマが含まれていても、同じセルにそのまま入力できます。カンマ・ダブルクォート・セル内改行を含む項目はCSV保存時に引用符で囲まれます。引用符を手作業で付ける必要はありません。テキストエディタで直接編集する場合は、項目を `"..."` で囲み、項目内の `"` は `""` と書きます。

### 項目名

| 対象 | 項目名と内容 |
| --- | --- |
| 論文3ファイル | `id` 番号、`year` 出版年、`authors` 著者、`title` タイトル、`journal` 掲載誌、`volume` 巻、`issue` 号、`pages` ページ、`url` リンク |
| 講演・学会発表 | `date` 日付・期間、`authors` 発表者・共著者、`event` 学会名・開催場所、`title` 題目 |
| メディア | `date` 日付、`title` 記事・媒体情報、`url` リンク |
| 来訪者 | `date` 来訪期間、`name_affiliation` 氏名・所属、`url` リンク |

`legacy_extra_1`〜`legacy_extra_4` は、古い講演データの余剰項目を失わずに保存する列です。ページには表示しません。新しい行では空欄で構いません。`id` は従来の論文番号を保持する列で、年の判定や並び順には使いません。巻・号・ページ・URLなど情報のない項目は空欄にできますが、列自体は残します。タイトル（来訪者では氏名・所属）と、論文の出版年は必須です。

### 日付と年

- 論文の `year`：`2028` のような西暦4桁。
- 通常の日付：`2028-03-25`。Excelが `2028/3/25` に変えて保存した場合も読み込めます。
- 月まで分かる場合：`2028-03`。日付を推測して補いません。
- 期間：`2028-03-01〜2028-03-15`。終了日不明なら `2028-03-01〜`。
- 複数の来訪期間：同じセルに `2028-03-01〜2028-03-05, 2028-03-20〜2028-03-25` のように記載できます。

期間・年月のみの値は、Excelで入力前にセルの表示形式を「文字列」にすると意図しない日付変換を避けられます。年は日付・期間の先頭から自動判定するので、別の年欄への二重入力は不要です。論文以外は開始日の新しい順、同年の論文はCSVの記載順で表示します。

タイトル・人名・掲載誌・学会名等を検索できます。空白区切りの複数語はすべてを含む記録を表示します。英字の大文字・小文字と全角・半角は区別しません。
各分類へ直接リンクする場合は `result.html#publications`、`#conferences`、`#media`、`#visitors` を使います。
